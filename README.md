# Маша и Лёша — свадебный сайт

React + TypeScript + MUI + Vite. Требуется Node.js 24+.

```sh
npm ci
npm run dev
npm run build
npm run typecheck
npm run lint
npm test
```

Браузерные тесты Playwright используют установленный Google Chrome и проверяют настольный и мобильный размеры. Запросы RSVP в тестах перехватываются, реальные ответы не отправляются.

## Структура

- `src/pages/InvitationPage.tsx` — приглашение, составленное из секций `components/invitation`.
- `src/pages/MemoriesPage.tsx` — свадебные фото и видео.
- `src/components/common` — общие ссылки, карточки, декор.
- `src/components/music` и `src/hooks/useAudioPlayer.ts` — общий UI плейлистов и управление аудио.
- `src/components/RSVPForm.tsx` — единственная форма подтверждения; тип отправки — `src/types/index.ts`.
- `src/locales/locales.ts` — все тексты интерфейса на русском и сербском. Ключи RU/SR проверяются TypeScript. Названия песен и исполнителей — данные в `src/data/music.ts`.
- `src/context/LanguageContext.tsx` — общий язык приложения; `useTranslation()` читает этот контекст. Выбор сохраняется в localStorage, при его недоступности работает в пределах сессии.

Навигация: `#/` — приглашение, `#/memories` — фото и видео. Hash-маршруты поддерживают прямое открытие, обновление и историю браузера без дополнительных настроек статического хостинга.

## Как добавить свадебные материалы

Откройте `src/data/weddingMedia.ts`:

1. Замените `previews`: импортируйте фотографии в `src/assets/images` или укажите URL в `src`. Превью не являются ссылками; переходы на материалы находятся только в текстовых карточках.
2. В `photos` укажите ссылки на альбомы, в `videos` — на фильмы. Можно добавлять несколько записей с уникальными `id`.
3. Подписи задаются ключами `titleKey`, `descriptionKey`, `actionKey` и `altKey` из `locales.ts`. Новые тексты добавляйте на обоих языках.
4. Поставьте `isPlaceholder: false`, чтобы скрыть сообщение о временных материалах.

Сейчас используются фотографии из путешествий, а все ссылки на материалы ведут на рикролл по просьбе владельца. При пустых массивах альбомов/видео показывается сообщение о скором появлении материалов.

## RSVP

Событие завершилось: блок подтверждения перечёркнут, поля и кнопка отключены. Компонент не вызывает отправку даже при программном событии submit. Текст уведомления находится в `locales.ts` (`eventEnded`). Сервис Google Apps Script сохранён отдельно, но в завершённом событии не используется.
