# Маша и Лёша — свадебный сайт

React + TypeScript + MUI + Vite. Требуется Node.js 24+.

```sh
npm ci
npm run dev
npm run build
npm run typecheck
npm run lint
npm test
```

Браузерные тесты Playwright используют установленный Google Chrome и проверяют настольный и мобильный размеры. Запросы RSVP в тестах перехватываются, реальные ответы не отправляются.

## Структура

- `src/pages/InvitationPage.tsx` — приглашение, составленное из секций `components/invitation`.
- `src/pages/PhotosPage.tsx` — ссылка на оригиналы и галерея сжатых фотографий.
- `src/pages/VideosPage.tsx` — ссылка на свадебное видео.
- `src/components/PhotoGallery.tsx` — адаптивная галерея с отложенной загрузкой.
- `src/components/common` — общие ссылки, карточки, декор.
- `src/components/music` и `src/hooks/useAudioPlayer.ts` — общий UI плейлистов и управление аудио.
- `src/components/RSVPForm.tsx` — единственная форма подтверждения; тип отправки — `src/types/index.ts`.
- `src/locales/locales.ts` — все тексты интерфейса на русском и сербском. Ключи RU/SR проверяются TypeScript. Названия песен и исполнителей — данные в `src/data/music.ts`.
- `src/context/LanguageContext.tsx` — общий язык приложения; `useTranslation()` читает этот контекст. Выбор сохраняется в localStorage, при его недоступности работает в пределах сессии.

Навигация: `#/` — приглашение, `#/photos` — фото, `#/videos` — видео. Старый адрес `#/memories` открывает страницу фото. Hash-маршруты поддерживают прямое открытие, обновление и историю браузера без дополнительных настроек статического хостинга.

## Как добавить свадебные материалы

Откройте `src/data/weddingMedia.ts`:

1. В `photos` замените `href` на ссылку на фотоальбом, в `videos` — на видео. Каждая ссылка отображается на своей странице.
2. Подписи задаются ключами `titleKey`, `descriptionKey` и `actionKey` из `locales.ts`. Новые тексты добавляйте на обоих языках.

Ссылка на фото ведёт на Google Drive. Ссылка на видео пока временная (рикролл); замените `href` в `videos`, когда фильм будет готов. Плеера пока нет. При пустых массивах ссылок показывается сообщение о скором появлении материалов.

Сжатые свадебные фотографии находятся в `public/photos`, список с размерами — в `src/data/photoGallery.json`. Галерея — горизонтальная лента без точек навигации, с исходными пропорциями фотографий и отложенной загрузкой. Фотографии отсортированы по номеру в имени файла слева направо. Под лентой постоянно виден ползунок: можно перетаскивать бегунок или нажимать на шкалу; его положение синхронизировано с прокруткой. Колесо мыши над лентой прокручивает её горизонтально; также работают горизонтальный жест трекпада, прокрутка касанием и клавиатура. На краях ленты колесо снова прокручивает страницу. По нажатию открывается предпросмотр по центру экрана без названия файла; закрытие — крестиком, Escape или нажатием на фон.

Для повторной подготовки фотографий установите Pillow в отдельное Python-окружение и запустите:

```sh
python3 -m venv /tmp/wedding-photo-tools
/tmp/wedding-photo-tools/bin/pip install Pillow
/tmp/wedding-photo-tools/bin/python scripts/compress-photos.py /path/to/Photos.zip
```

Скрипт читает изображения прямо из архива, учитывает ориентацию EXIF, уменьшает длинную сторону до 1280 px и сохраняет WebP с качеством 76 без EXIF-метаданных. Исходный архив не изменяется. При замене альбома удалите старые файлы из `public/photos` перед запуском, чтобы они не попадали в сборку.

## RSVP

Событие завершилось: блок подтверждения перечёркнут, поля и кнопка отключены. Компонент не вызывает отправку даже при программном событии submit. Текст уведомления находится в `locales.ts` (`eventEnded`). Сервис Google Apps Script сохранён отдельно, но в завершённом событии не используется.
